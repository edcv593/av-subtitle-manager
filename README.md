# AV Subtitle Manager — 极空间 Z4 Pro

独立 Docker 自动字幕管理器：扫描影片、识别番号、迅雷字幕 API 搜索、严格匹配自动下载、失败重试、Web 管理界面。不依赖 Stash，不需要 .env。

## 部署
1. 克隆或下载本仓库到极空间 Docker 项目文件夹。
2. 编辑 `docker-compose.yml`，将 `/请修改为极空间实际影片路径` 改成影片真实绝对路径；把 `WEB_TOKEN` 改成强密码。
3. 在项目目录运行 `docker compose up -d --build`，或使用极空间 Docker Compose 项目管理功能。
4. 浏览器访问 `http://极空间IP:8765`，输入令牌。
5. 初次测试可将 `AUTO_DOWNLOAD` 设置为 `"false"`，验证匹配后再开启。

## 默认规则
- 每 6 小时扫描；未找到/失败/多候选每 24 小时重试；新文件至少稳定 30 分钟。
- `IPX-123-C.mp4`、`IPX-123-破解-C.mp4` 直接跳过。
- 已存在同名外挂字幕跳过；**不检查 MKV 内封字幕**。
- 只有唯一候选、番号一致、文件名有中文字幕标记且内容符合字幕格式才自动保存。
- 多候选在 Web 界面人工选择；以排他模式新建字幕文件，不覆盖原文件。
- 状态存储在 `data/subtitle.db`，请定期备份。

## 注意
- 迅雷 API 是第三方接口，可能变更、失效或限流；**尚未完成极空间实机和 API 端到端验证**。
- 字幕匹配校验不能保证字幕语言和时间轴一定正确。
- Web 端口仅限局域网，不要直接开放公网。
- Compose 需要支持本地镜像构建。容器默认以 root 运行以适配 NAS 目录权限；生产环境建议调整为非 root。
- 请确保使用的媒体与字幕符合适用法律和授权要求。
